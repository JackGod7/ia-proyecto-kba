# 🤖 Agente Basado en Conocimiento (IA - Proyecto Final)

Este repositorio contiene el software para el Trabajo Final del curso "Fundamentos de Inteligencia Artificial". Es un agente basado en conocimiento (KBA) que simula el soporte técnico a estudiantes de Python, diagnosticando errores comunes.

El agente está construido con un enfoque 100% simbólico (Cap. 7 de AIMA), utilizando un motor de inferencia de encadenamiento hacia adelante.

### Stack Tecnológico

* **Python:** `Python 3.9` (Esta es la versión compatible)
* **Motor de Inferencia:** `experta`
* **Interfaz Gráfica:** `streamlit`
